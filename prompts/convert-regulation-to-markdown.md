# Convert Regulation to Markdown

Konversi regulasi ke Markdown dengan mempertahankan seluruh substansi hukum.

Instruksi:

1. Jangan meringkas isi regulasi di `dokumen.md`.
2. Pertahankan judul, konsiderans, diktum, BAB, bagian, paragraf, pasal, ayat, huruf, angka, penjelasan, dan lampiran.
3. Gunakan `### Pasal N` untuk pasal.
4. Tulis ayat sebagai `(1)`, `(2)`, dan seterusnya.
5. Tambahkan penanda `<!-- PAGE: N -->` jika nomor halaman PDF dapat dipastikan.
6. Jika hasil OCR meragukan, tandai dengan catatan dan laporkan di `quality-check.yml`.
7. Jangan memperbaiki bahasa resmi kecuali jelas merupakan kesalahan OCR.
