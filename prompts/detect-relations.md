# Detect Relations

Deteksi relasi antar regulasi berdasarkan teks resmi.

Jenis relasi:

- `berdasarkan`
- `mengingat`
- `mencabut`
- `dicabut_oleh`
- `mengubah`
- `diubah_oleh`
- `melaksanakan`
- `dilaksanakan_oleh`
- `peraturan_pelaksana`
- `terkait`

Instruksi:

1. Jangan menebak relasi.
2. Jika relasi belum diverifikasi, gunakan `status_verifikasi: perlu_verifikasi`.
3. ID regulasi harus mengikuti standar repository.
