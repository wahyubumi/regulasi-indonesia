# Extract Metadata

Ekstrak metadata regulasi dari teks atau sumber resmi.

Instruksi:

1. Jangan mengarang data yang tidak tersedia.
2. Gunakan `null`, `belum_diisi`, atau `perlu_verifikasi` untuk data yang belum pasti.
3. Isi `id` sesuai standar repository.
4. Isi `judul_lengkap` berdasarkan nama resmi regulasi.
5. Catat sumber resmi di `source.yml`.
6. Simpan relasi hanya jika ada dasar dalam teks regulasi atau sumber resmi.
