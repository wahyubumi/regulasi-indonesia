# Standar Penamaan File

Gunakan huruf kecil, angka, dan tanda hubung.

Format regulasi pusat:

```text
regulasi/pusat/[jenis]/[tahun]/[jenis]-[tahun]-[nomor-3-digit]-[slug-judul]/
```

Format regulasi lembaga:

```text
regulasi/lembaga/[lembaga]/[tahun]/[jenis]-[tahun]-[nomor-3-digit]-[slug-judul]/
```

Format regulasi daerah:

```text
regulasi/daerah/[level]/[kode-wilayah]-[nama-daerah]/[jenis]/[tahun]/[jenis]-[nama-daerah]-[tahun]-[nomor-3-digit]-[slug-judul]/
```

Aturan slug:

- Gunakan huruf kecil.
- Ganti spasi dengan tanda hubung.
- Hapus tanda baca yang tidak perlu.
- Gunakan nomor 3 digit untuk menjaga urutan.
- Simpan nomor asli lengkap di `metadata.yml`.
