# Standar Markdown

Gunakan struktur berikut:

```markdown
# Judul Regulasi

## Konsiderans

### Menimbang

a. bahwa ...

### Mengingat

1. ...

## Diktum

MEMUTUSKAN:

Menetapkan: ...

## BAB I
## KETENTUAN UMUM

### Pasal 1

(1) Isi ayat.

(2) Isi ayat.
```

Aturan:

- `#` untuk judul utama.
- `##` untuk bagian besar.
- `###` untuk pasal.
- Ayat menggunakan `(1)`, `(2)`, dan seterusnya.
- Huruf menggunakan `a.`, `b.`, dan seterusnya.
- Angka menggunakan `1.`, `2.`, dan seterusnya.
