# Panduan Konversi

1. Identifikasi sumber resmi regulasi.
2. Jangan menyimpan PDF asli di Git.
3. Jika perlu file sementara, gunakan `downloads/` atau `tmp/`.
4. Ekstrak teks dan pertahankan struktur resmi.
5. Tambahkan penanda halaman jika dapat dipastikan.
6. Jangan meringkas substansi hukum di `dokumen.md`.
7. Simpan tabel besar sebagai CSV di `assets/tables/`.
8. Simpan diagram sebagai Mermaid atau deskripsi teks jika dapat diverifikasi.
9. Isi `metadata.yml`, `source.yml`, `relasi.yml`, dan `quality-check.yml`.
10. Jalankan validasi sebelum commit.
