# Standar Metadata

`metadata.yml` wajib tersedia di setiap folder regulasi.

Aturan:

- Gunakan spasi, bukan tab.
- Gunakan `null` untuk nilai tanggal atau angka yang belum diketahui.
- Gunakan `[]` untuk daftar kosong.
- Gunakan tanda kutip untuk string yang mengandung tanda titik dua.
- Jangan mengarang tanggal, nomor lembaran negara, status berlaku, atau relasi regulasi.
- `id` harus konsisten dengan nama folder dan indeks.

Template lengkap tersedia di `metadata-schema.md`.
